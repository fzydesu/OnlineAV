# 🎬 OnlineAV

局域网同步看视频 —— 一个人放，一群人看，进度实时同步。

## ✨ 功能

- **房间制** — 创建一个房间，把房间码分享给朋友，大家一起加入
- **同步播放** — 主持人的播放/暂停/跳转操作实时同步到所有观众
- **周期性校准** — 每 5 秒自动校准播放进度，确保所有人都看到同一画面
- **本地视频上传** — 拖拽上传 MP4/MKV/WebM 等格式，最大支持 15GB
- **B站视频同步** — 输入 BV 号，和朋友一起看 B 站视频（开发中）
- **一键分享** — 生成分享链接 ` /w/房间码`，打开即可加入
- **自动清理** — 空房间 1 小时后自动回收，视频文件一并清除

## 🚀 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动服务
npm start
```

## 📖 使用方式

### 主持人

1. 打开页面，拖拽视频文件到上传区域（或点击选择）
2. 点击「创建房间」
3. 将房间码或分享链接发给朋友
4. 使用视频播放器控制播放 —— 你的操作会自动同步给所有人

### 观众

1. 打开主持人分享的链接，或手动输入房间码
2. 自动加入房间，开始同步观看
3. 无需任何操作 —— 进度跟随主持人

## 🛠️ 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Node.js + Express |
| 实时通信 | Socket.IO |
| 文件上传 | Multer |
| 前端 | 原生 HTML/CSS/JS（无框架） |

## 📁 项目结构

```
OnlineAV/
├── server.js          # 服务器入口：Express、Socket.IO、房间管理
├── public/
│   ├── index.html     # 前端页面（三视图：首页/主持人/观众）
│   ├── app.js         # 前端逻辑：Socket 通信、播放器控制、上传
│   └── style.css      # 样式
├── uploads/           # 上传的视频文件（git 忽略）
└── package.json
```

## ⚙️ 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务器端口 |

## 📝 注意事项

- 所有设备需要在**同一局域网**内
- 视频文件上传到服务器本地，磁盘空间要够
- 浏览器必须支持 H.264 编码的 MP4 格式才能直接播放（Chrome/Firefox/Edge 均可）
- 如果视频无法播放，请转换为 H.264 MP4 格式
